# NIFTY50-FNO-Volatility-Analysis
# Impact of Futures & Options Trading on NIFTY 50 Volatility

## Project Overview

This project investigates the relationship between Futures and Options (F&O) trading activity and volatility in the Indian stock market, focusing on the NIFTY 50 index.

Using historical market and derivatives data from 2021 to 2026, the study applies Python-based data analysis, statistical techniques, econometric regression, and machine learning to examine whether derivatives trading activity is associated with changes in market volatility.

## Objectives

- Analyse historical NIFTY 50 price movements and volatility patterns.
- Examine the relationship between F&O trading activity and market volatility.
- Build regression models to identify significant relationships.
- Develop forecasting models to predict next-day absolute market returns.
- Evaluate model performance using RMSE and MAE.

## Tools & Technologies

Python | Pandas | NumPy | Matplotlib | Seaborn | Statsmodels | Scikit-learn | Jupyter Notebook

## Key Highlights

- Analysis of historical NIFTY 50 and F&O market data.
- Exploratory data analysis and visualisation of market trends.
- Econometric regression using HAC-robust standard errors.
- Comparison of market-only and market-plus-F&O forecasting models.
- Model evaluation using statistical and forecasting performance metrics.

## Research Note

The project is an empirical study of the relationship between derivatives activity and market volatility. The findings indicate statistical associations and predictive patterns; they should not be interpreted as proof of causation.
